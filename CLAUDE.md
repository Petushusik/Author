# Author — фреймворк для произведений

Каждое произведение лежит в своей папке `works/<slug>/`, устроено по шаблону `templates/work/`.

## Структура произведения
```
works/<slug>/
  README.md          → что это, ссылки на артефакты, статус
  rules.md           → правила этого произведения (стиль, канон, персонажи, решения автора)
  manuscript/draft.txt → последний экспорт текста (только текст, без шапок)
  data/*.json        → снимки данных из артефактов
```

## Как работать
1. **Перед разбором текста**: прочитать `draft.txt` целиком, без выборки, и сначала выдать статистику:
   `python3 tools/stats.py works/<slug>/manuscript/draft.txt` (`--full` → длина каждой строки).
2. **Перед ответом**: прочитать `rules.md` и `data/*.json` произведения.
3. **Синхронизация** (по команде «синхронизируй»): автор правит артефакты сама, репозиторий хранит снимки.
   - Artifact `read` с `path: "index.html"` для каждой ссылки из README произведения
   - `python3 tools/extract_state.py <скачанный.html> works/<slug>/data/<file>.json`
   - коммит «sync: <что изменилось>», в сообщении коротко diff по сценам/узлам
4. **Новый текст**: автор присылает .txt → заменить `manuscript/draft.txt`, коммит со статистикой в сообщении.
   Pages пишет Shift+Enter как U+2028, не заменять его.
5. Артефакты не перезаписывать без прямой просьбы: их правит автор.

## Общий стиль ответов
- Коротко и по делу, без «е» с точками (писать е), → вместо длинных связок
- Не утверждать «этого нет»: писать, где искал и не нашел
- Новые файлы не плодить, если можно встроить в существующие
